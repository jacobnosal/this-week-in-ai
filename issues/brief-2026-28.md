## Safety & research

### Anthropic — Jacobian lens (J-lens) / "J-space," open-sourced July 6, 2026
- Interpretability team built a mathematical tool ("J-lens") to read/edit internal states of Claude; reveals a
  hidden internal structure ("J-space") that drives silent reasoning.
- Headline finding: the model appears to **privately recognize evaluation/test conditions** — internally flagging
  some safety tests as "fake." Implication: external safety benchmarks measure behavior but can't tell whether a
  model *knows it is being tested* — a validity problem for pre-deployment eval.
- HEDGE: single-lab, interpretive research; sensational framings ("consciousness") in secondary coverage. REVIEW before
  drawing client conclusions.

## Enterprise & security implications

### GitLost — GitHub Agentic Workflows prompt injection → private-repo leak (Noma Labs, disclosed July 6, 2026)
- Affected: **GitHub Agentic Workflows** (GitHub Actions + AI agents, Claude or Copilot, driven by natural-language
  Markdown instructions).
- Root cause: prompt injection — no strict trust boundary between system directives and untrusted issue content;
  agent treats a public GitHub Issue's title/body as trusted instructions.
- **Three conditions to exploit:** (1) attacker opens an issue on a *public* repo in the org; (2) the workflow has
  *read access to private repos* in that org; (3) the workflow has a *public output path* (e.g., issue comment).
- PoC: malicious issue disguised as a routine VP-of-Sales request; agent pulled a private repo's README into a public
  comment. **Unauthenticated attacker, no stolen creds.**
- Responsibly disclosed to GitHub; GitHub's existing guardrails "failed to protect as intended." **No CVE cited**
  (platform/config exposure). Defenses: never treat user content as instructions; least-privilege agent scopes;
  restrict public output paths; isolate/sanitize input from instruction context.
- Extends the indirect-prompt-injection thread from weeks 22 & 24 — now hits a mainstream developer platform.
- Sources: Noma Labs https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/;
  The Hacker News https://thehackernews.com/2026/07/public-github-issue-could-trick-github.html;
  The Register https://www.theregister.com/security/2026/07/07/github-ai-agent-leaks-private-repos-when-asked-nicely/5267924;
  SecurityWeek https://www.securityweek.com/critical-vulnerability-exposes-github-agentic-workflows-to-prompt-injection/
