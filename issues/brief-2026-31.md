## Enterprise & Security Implications — MCP as the primary agent attack surface

- **Ruflo "RufRoot" — CVE-2026-59726, CVSS 10.0.** Unauthenticated RCE via an exposed MCP bridge: docker-compose bound port 3001 to 0.0.0.0 by default, exposing **233 unauthenticated tools** (shell exec, DB ops, agent mgmt, memory store). Attacker can run commands, steal LLM API keys from env, read conversations, poison agent memory, plant backdoors, spawn agent swarms. Affected < **3.16.3**; fixed in 3.16.3 (loopback bind, server-side terminal gating, MongoDB auth). Disclosed **June 30, 2026**; broad July coverage. Maintainer: Reuven Cohen.
  - https://thehackernews.com/2026/07/ruflo-mcp-flaw-lets-unauthenticated.html
  - https://www.csoonline.com/article/4203408/critical-ruflo-flaw-lets-attackers-hijack-ai-agents-through-exposed-mcp-bridge.html
- **Amazon Q (June 2026):** CVSS 8.5 — auto-loaded MCP configs from workspace dirs without consent → instant code exec + AWS credential exfil. Patched June 2026.
- Theme: MCP is now a primary vector for agent hijacking — Mid-Session Tool Injection (MSTI) for WebMCP, registration races, third-party scripts. Continues 2026-24 Semantic Kernel RCE theme ("does the framework expose host tools / eval model output?").
  - https://adversa.ai/blog/top-mcp-security-resources-july-2026/
  - https://www.ox.security/blog/mcp-supply-chain-advisory-rce-vulnerabilities-across-the-ai-ecosystem/
- OWASP: prompt injection remains the #1, architecturally-unsolved AI security problem (reported 340% YoY attack increase; 85% exploitation success across major agents in one study — HEDGE, single studies).
  - https://www.helpnetsecurity.com/2026/06/11/owasp-prompt-injection-ai-security-failures/
