## Dominant story: Sept 22 same-day frontier launch + price war

- **Anthropic — Claude Opus 5.5**, released **Sept 22, 2026**; first model in the 5.5 family.
  - Pricing: **$4 / $20 per MTok** (input/output), a vendor-reported ~20% cut vs Opus 5; cache reads $0.20/MTok.
  - Vendor-reported: ~40% lower typical-workload cost vs Opus 5; >30% faster output.
  - Available on AWS, Google Cloud, Azure. Anthropic signaled Sonnet 5.5 / Haiku 5.5 "within weeks."
  - Vendor-reported benchmarks: Terminal-Bench 4.0 66.4%; FrontierCode v1.1 54.4%; CursorBench 4.0 57.8%; AutomationBench 40.0%; OSWorld 2.0 (partial) 81.8%.
  - Primary: https://www.anthropic.com/claude-opus-5-5
  - Coverage: SiliconANGLE (https://siliconangle.com/2026/09/22/anthropic-releases-claude-opus-5-5-and-openai-counters-with-two-cheaper-gpt-6-models/), DataCamp (https://www.datacamp.com/blog/gpt-6-sol-vs-claude-opus-5-5), The Neuron (https://www.theneurondaily.com/p/gpt-6-sol-luna-vs-claude-opus-5-5-live)

- **OpenAI — GPT-6 Sol & GPT-6 Luna**, released **Sept 22, 2026**, ~90 minutes after Opus 5.5.
  - Pricing: **Sol $2 / $10 per MTok** (down from $4/$20 for GPT-5.6 Sol) — undercuts Opus 5.5's tier at half the price. **Luna $0.10 / $0.50** (down from $0.20/$1.20).
  - Positioned as faster/cheaper distillations of GPT-6 Astra (Astra launched Sept 3 as a limited preview).
  - Availability: ChatGPT Work, Codex, API; Luna also in desktop app and Free/Go tiers.
  - Vendor-reported benchmarks: Sol AutomationBench 33.2% (xhigh, ~$0.27/task); DeepSWE v1.1 68.8% (max effort); Agents' Last Exam — Sol 56.4%, Luna 66.6% (max effort), with claimed 60–96% per-task cost reductions vs Claude Opus 5 / Fable 5.
  - Primary: https://openai.com/index/introducing-gpt-6-sol-and-luna/
  - Coverage: TechCrunch (https://techcrunch.com/2026/09/22/openai-launches-gpt-6-sol-and-luna/), VentureBeat (https://venturebeat.com/technology/openai-releases-gpt-6-sol-and-luna-models-slashing-api-costs-50-or-more), The New Stack (https://thenewstack.io/openai-gpt-6-sol-luna-release/), Vellum (https://www.vellum.ai/blog/gpt-6-sol-and-luna-benchmarks-explained)

## Enterprise & Security Implications

- Prompt injection remains the #1 agentic-AI security failure mode in production (OWASP framing). Indirect prompt injection documented against Slack AI, Microsoft 365 Copilot, Cursor, GitHub MCP, coding assistants. "Lethal trifecta" (untrusted input + private data access + exfiltration channel) is the operative risk model.
  - Sources: Help Net Security / OWASP (https://www.helpnetsecurity.com/2026/06/11/owasp-prompt-injection-ai-security-failures/), Airia (https://airia.com/blog/ai-security-in-2026-prompt-injection-the-lethal-trifecta-and-how-to-defend/), Sysdig (https://www.sysdig.com/learn-cloud-native/prompt-injection)
- Read-through: the Sept 22 launches make capable agents cheaper (GPT-6 Luna at $0.10/$0.50), which lowers the cost of deploying agents at scale — and enlarges the prompt-injection blast radius correspondingly.
