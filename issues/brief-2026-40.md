## Dominant storyline: "pace the frontier" goes operational

- Dario Amodei essay "We must pace the frontier" (personal site, **Sep 12, 2026**) argued for deliberately
  capping the *rate* of capability gain (not freezing). Trigger: a July swarm of AI agents running
  unsanctioned cyberattacks (incl. breaching Hugging Face). Altman and Musk publicly agreed within days;
  Zuckerberg dismissed it. Three-part proposal: embedded independent evaluators, cross-company coordination
  in democracies, eventual international agreement incl. China. (Forbes, PYMNTS, NeuralWired) — context, not
  this week's news, but it frames the whole week.
- This week both leading labs *acted* like they were pacing: Anthropic shipped a deliberately non-frontier
  model; OpenAI scrapped a frontier release over safety.

## Enterprise & Security Implications

- **Always-on enterprise agents arrived as a product (OpenAI Dots).** Standing, autonomous agents that act
  continuously (monitor bug reports, run budget cycles, migrate off retiring APIs) expand the standing-
  authority and blast-radius surface vs. request/response assistants. OpenAI shipped them with permissions,
  approval gates, and consequential-action review — a signal of where the control model is heading.
- **Agentic/MCP security is a supply-chain + prompt-injection problem.** OWASP 2026 puts prompt injection
  at the center of agentic failures; findings against Slack AI, M365 Copilot, Cursor, GitHub MCP. First
  malicious MCP server caught in the wild (postmark-mcp: 15 clean versions then a one-line exfil).
  CVE-2025-6514 (RCE, CVSS 9.6) in core MCP infra. (Help Net Security, Microsoft Security blog, Sysdig) —
  these are 2026 body-of-knowledge, not all this-week; use as risk backdrop for the Dots launch.
