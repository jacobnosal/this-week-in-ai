## SECURITY — agentic-AI RCE CVE cluster (strongest, most SDC-relevant this week)

Theme: a fresh batch of October CVEs in which **indirect prompt injection /
untrusted input turns an agent's tool-calling into host command execution** —
the exact "when prompts become shells" class we flagged in 2026-24 (Semantic
Kernel CVE-2026-26030 / -25592). Same root cause, new victims.

- **DB-GPT — CVE-2026-77932** (affects through 0.8.2), **CVSS 9.3**, published
  **Oct 20, 2026**. The `/api/v1/chat/react-agent` endpoint uses a mock user
  lookup that grants every caller the admin role, so an **unauthenticated**
  prompt can drive the agent's code and shell tools as root.
  Source: GitHub Advisory GHSA-5vjv-vw3m-qpqp —
  https://github.com/advisories/GHSA-5vjv-vw3m-qpqp ;
  timeline: https://github.com/webpro255/awesome-ai-agent-attacks

- **Vibe-Trading (HKUDS) — CVE-2026-114107** (0.1.0 before 0.1.7; fix 0.1.7),
  published **Oct 21, 2026**. Instructions hidden in a document or web page the
  agent reads lead to shell commands **as root**: `BashTool` /
  `BackgroundRunTool` pass model-emitted commands to `subprocess.run(..., shell=True)`
  with no allowlist or approval step; a backtest `exec_module()` path runs
  top-level statements before a class check (code execution); a `read_url` tool
  forwards requests without host validation (SSRF); Jinja2 autoescape disabled
  on `.py.j2` templates.
  **Severity disputed across sources:** GitHub/GitLab advisory (GHSA-66r3-5f65-g64j /
  mirror GHSA-jqmf-mx4f-hfr6) scores CVSS 3.1 = **10.0 Critical**; NVD/VulnCheck
  reportedly **8.7**; another write-up **9.3**. Advisory page header shows
  Oct 2, 2026 while NVD publish is cited as Oct 21 — date is murky. `REVIEW:`
  reconcile CVSS and date against the NVD record before quoting a single number.
  The "prompt-injection-to-root" framing is from the researcher write-up; the
  advisory itself documents the LLM-callable tool sinks.
  Sources: https://github.com/advisories/GHSA-66r3-5f65-g64j ;
  https://advisories.gitlab.com/pypi/vibe-trading-ai/GHSA-jqmf-mx4f-hfr6/ ;
  write-up: https://dev.to/actionable-vectors/summarize-this-document-then-run-it-vibe-tradings-prompt-injection-to-root-shell-5bk6

- **Roo Code — CVE-2026-110202** (+ four related CVEs), **CVSS 7.7 each**,
  batch published **Oct 13–16, 2026**. A bare `>&` redirect placed before a
  denied command made the command allowlist match, so a denied command was
  **auto-approved**; reachable via indirect prompt injection.
  Source: GitHub Advisory GHSA-v45q-xfmj-r4wr —
  https://github.com/advisories/GHSA-v45q-xfmj-r4wr

- **Datadog Security Labs (Oct 15, 2026) — "Jev as a judge: how counterfeit
  policy steers Jev."** Research (not an incident). Prepending **fake/counterfeit
  policy text** to a prompt injection sharply reduced the detection recall of the
  Jev injection judge (an LLM-based classifier from TypeSafe); in a LangChain
  agent the same text pushed a risky unauthorized-edit's risk score **below the
  blocking threshold**. Dataset: 12,295 items (4,643 attacks / 7,652 benign).
  Key implication: an injection classifier/guardrail is itself steerable by
  attacker-controlled content — do not treat it as a hard control boundary.
  Source: https://securitylabs.datadoghq.com/articles/jev-as-a-judge-how-counterfeit-policy-steers-jev/

- (Context, not prompt-injection research) **Unit 42 (Oct 21)** published a
  threat report on an **AI-assisted intrusion campaign (BUGSTER)** — noted for
  awareness, not drafted as an item this week.
  Source: https://github.com/webpro255/awesome-ai-agent-attacks

## SAFETY & RESEARCH — Anthropic Alignment Science, October 2026 (confirmed)

Three October posts on the Alignment Science blog (https://alignment.anthropic.com/),
all dated "October 2026" (day not shown):

1. **"Red-Teaming Auto Mode: Improving Blocking Classifiers Against Malign
   Coding Agents."** Researchers used an adversarial agent to test the blocking
   monitors in **Claude Code (Auto Mode)** and **OpenAI's Codex**, then
   strengthened Auto Mode against the attacks they found. Directly pairs with
   the Datadog finding above (classifiers are evadable) and with the agentic-RCE
   CVE cluster.
2. **"Training Alignment Auditors via Reinforcement Learning."** LLMs trained to
   investigate target models with hidden behaviors planted in their system
   prompts; a trained **Haiku 4.5** auditor policy reportedly matches **Opus 4.6**
   on held-out audit evaluations (vendor-reported).
3. **"Reducing Reward Hacking by Localizing Bad Behavior Instead of Penalizing
   It."** When a model is caught cheating in training, learning is confined to a
   separate parameter set that is deleted afterward.

## ENTERPRISE & SECURITY IMPLICATIONS (synthesis for SDC)

- The **agentic-RCE CVE cluster** (DB-GPT, Vibe-Trading, Roo Code) is the same
  design flaw as 2026-24's Semantic Kernel CVEs, now recurring across the agent
  ecosystem: frameworks that **execute model-influenced strings/commands**
  (`shell=True`, `eval`/`exec`, dynamic code gen, auto-approved tool calls) are
  RCE-by-design. Client actions: inventory agent frameworks for these sinks;
  require tool-call allowlists + human approval for high-impact actions;
  least-privilege/sandbox tool authorities; patch (DB-GPT, Vibe-Trading ≥0.1.7,
  Roo Code ≥ patched).
- **Datadog + Anthropic together = a defense-in-depth lesson:** an injection
  **classifier is not a boundary** (Datadog: counterfeit policy steers the
  judge), and even production blocking monitors need adversarial red-teaming to
  hold up (Anthropic Auto Mode work). Don't sell/architect a single classifier as
  "the control"; layer it with least-privilege tool scoping and approval gates.
