### Model Releases & Benchmarks

**Anthropic — Claude Haiku 5.5 (Oct 7, 2026)**
- Small model for high-volume work (summarization, subagents, browser use). API id `claude-haiku-5-5`.
- Pricing (per 1M tokens, secondary sources — no primary pricing page retrieved): ≤100K-token prompts $0.10 in / $0.50 out; >100K prompts $0.50 in / $2.50 out. Haiku 4.5 comparable was $1 / $5.
- Anthropic *claims* ~75% cheaper to run than predecessor; short-prompt tier is a ~90% cut.
- First Haiku with effort controls + adaptive thinking (default medium). Vendor-reported: 72.4% vs 15.7% (Haiku 4.5) on OSWorld 2.1 offline subset; 45.9% Humanity's Last Exam. Context 1M.
- Sources: https://aiweekly.co/alerts/introducing-claude-haiku-55 · https://pasqualepillitteri.it/en/news/21513/anthropic-launches-claude-haiku-5-5-pricing · https://letsdatascience.com/news/anthropic-releases-claude-haiku-55-with-lower-prices-and-eff-f698c663

**Google — Gemini 4 Argon (announced Sep 30; Fairwind rollout ongoing this week)**
- New flagship; not broadly available. Rolling out first to vetted cyber defenders via the Fairwind Program; paid API + AI Ultra "next," no date.
- Vetted defenders + internal teams get a cyber-guardrail-free version. Google says Argon can autonomously find, validate, and patch critical software vulnerabilities. Claims indirect-prompt-injection protections (adversarial training + automated red-teaming).
- 1M-token context (secondary). Google said the model is already used internally to optimize datacenter memory (reportedly freed "hundreds of terabytes").
- Sources: https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/ · https://www.securityweek.com/google-launches-gemini-4-argon-with-guardrail-free-access-for-vetted-defenders/ · https://techwireasia.com/2026/10/google-gemini-4-argon-cybersecurity-access/ · https://thenextweb.com/news/google-gemini-4-argon-cyber-defenders-fairwind

### Enterprise & Security Implications

**Gemini 4 Argon's guardrail-free defender access + Wiz "Scan for Good"**
- Wiz reportedly using Argon via "Scan for Good" (public-infrastructure defense); reportedly found a critical vuln in hospital healthcare software that earlier models missed (vendor-reported).
- Google frames staged access as an "adaptation window" for defenders before offensive parity.
- Trade-off to flag for clients: guardrail-free frontier vuln-finding accelerates defense but raises leak/misuse risk.
- Sources: https://www.securityweek.com/google-launches-gemini-4-argon-with-guardrail-free-access-for-vetted-defenders/ · https://thenextweb.com/news/google-gemini-4-argon-cyber-defenders-fairwind

**Indirect prompt injection — NIST taxonomy + Five Eyes agentic guidance (reference framing)**
- NIST AI 100-2 E2025 adversarial-ML taxonomy explicitly covers indirect prompt injection (malicious instructions planted in data an agent later reads). CSA note: resistant to input validation alone. May 2026 Five Eyes (CISA/NSA/UK/CA/AU/NZ) agentic-AI guidance relevant.
- Sources: https://labs.cloudsecurityalliance.org/research/csa-research-note-nist-ai-agent-red-teaming-standards-202603/ · https://www.ibm.com/think/insights/ai-prompt-injection-nist-report · https://www.sysdig.com/learn-cloud-native/prompt-injection
