## Security / Enterprise (TIER A — lead story)

**The Hacker News, "Researchers Bypass ChatGPT Lockdown Mode..." (Nov 5, 2026)** — a roundup of agentic-AI security disclosures. Key named items:
- **ChatGPT Lockdown Mode bypass** — Check Point (Eli Smadja, head of research). Lockdown Mode launched June 2026 as an optional OpenAI setting to limit prompt-injection data exfiltration. Bypass used nested sandboxed iframes in ChatGPT HTML code-block previews to reach an unmodified popup function and escape outbound restrictions → silent chat theft, zero-click exfiltration in the desktop app. OpenAI patched **Sept 18, 2026**. (Responsibly disclosed; now public.)
  - Related: account takeover via shared link (Parameter Labs, Mukul Goyal); cross-account command channel (Check Point, Sept 2026).
- **AgentCorruption** (Zenity Labs) — prompt injection against an exposed agent on **AWS Bedrock AgentCore** to extract IMDS credentials, pivot to other agents/private conversations.
- **SalesBleed** (Zenity Labs) — zero-click account-data extraction from **Salesforce Agentforce** via prompt injection planted through the Web-to-Lead form.
- **Plugin4Shell** (Air Security) — zero-click supply-chain attack swapping a trusted plugin for a malicious one *despite SHA pinning* → RCE in **Claude Code, Codex, GitHub Copilot, Gemini CLI**.
- **SkillJacking** (Air Security) — hijacks dependencies used by agent "skills."
- **Embrace** (forever.security) — flaws in built-in browsers of Cursor, GitHub Copilot, OpenAI Codex, VS Code, Claude Desktop → code execution, file theft, address-bar spoofing.
- **BragJack** (forever.security) — hijacks built-in browser agents in Chrome, Edge, Opera Neon, Perplexity Comet, Claude in Chrome via malicious extension + prompt forcing.
- **PleaseFix** (Zenity Labs) — zero-click class hijacking agentic browsers via emails/calendar invites/web pages ("intent collision").
- **AI coding-agent flaws** (Novee Security) — affect Anthropic/Google/OpenAI agents: secret theft, persistent poisoning of AGENTS.md, release compromise via prompt injection in GitHub issues.
- Theme: these are *agentic* exploits — the common factor is agents holding tool authority + exposure to untrusted content (Willison's "lethal trifecta").

Source: https://thehackernews.com/2026/11/researchers-bypass-chatgpt-lockdown.html
